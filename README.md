# Cosmos Raro

Kit del canal de YouTube Shorts **Cosmos Raro**: un dato imposible del universo, cada día a las 19:00 (Madrid).

- `MANUAL.md` — cómo se produce cada reel (lo sigue el agente diario).
- `agujero/` — short completo de referencia (Remotion + Three.js, motor de `shorts-animados-claude`).
- `venus_world/` — segundo mundo de ejemplo (superficie de un planeta).
- `reels/AAAA-MM-DD_tema/` — guion, fuentes y código de cada reel publicado (sin los vídeos, que no caben aquí).

Motor y estilo: https://github.com/luispablovillasenor-afk/shorts-animados-claude
